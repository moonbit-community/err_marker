# cursor design

## The problem

To put a marker under part of a line, a program must know the column where
the text before it ends. Counting characters is not enough: a wide character
takes two columns, a combining accent none, a tab jumps to the next tab stop
and a line break starts a new line. The package models each of these as a
move of the cursor and composes moves.

## Moves

Write $t \ge 1$ for the tab width and $T(x) = t(\lfloor x/t \rfloor + 1)$ for
the next tab stop after column $x$. A grapheme cluster $g$ acts on the cursor
$(\ell, c)$ as

$$
c \mapsto c + w(g), \qquad c \mapsto T(c) \text{ for a tab}, \qquad
(\ell, c) \mapsto (\ell + 1, 0) \text{ for a line break}.
$$

Composition of functions makes these moves a monoid. Laying out a text is
the monoid homomorphism from cluster sequences that sends each cluster to its
move, so the end position of $uv$ is computed from the moves of $u$ and $v$.

## Three normal forms

Every composite move has exactly one of the forms

$$
S_k : c \mapsto c + k, \qquad
U_{a,b} : c \mapsto T(c + a) + b \ (0 \le a < t), \qquad
B_{n,k} : (\ell, c) \mapsto (\ell + n, k) \ (n \ge 1).
$$

They are closed under composition. A line break forgets the column, so
anything followed by $B_{n,k}$ is a $B$, and $B$ followed by a column move
stays a $B$ with a new column. Shifts add. A shift before a tab move is
absorbed by $T(x + qt + r) = T(x + r) + qt$, which keeps $a < t$. Two tab
moves combine because $T(x)$ is a multiple of $t$, so

$$
T(T(x) + d) = T(x) + T(d) \quad (d \ge 0),
$$

and $U_{a_2,b_2} \circ U_{a_1,b_1} = U_{a_1,\, T(b_1 + a_2) + b_2}$.

The forms are canonical: two different values act differently on some
position. $S_k$ is strictly increasing, $U_{a,b}$ is constant on runs of
$t$ columns that start at $c = t - a$ (for $t \ge 2$), and $B$ changes the
line. With $t = 1$ a tab is $c \mapsto c + 1$, so the model represents it as
$S_1$ and no $U$ ever appears; this keeps the forms unique.

## Widths

Cluster widths come from the Unicode Character Database 18.0.0, through
tables generated by `tools/gen_unicode_tables.py`:

- **Standard (UAX #11):** East Asian Wide and Fullwidth are 2, Neutral,
  Narrow and Halfwidth are 1.
- **Standard (UAX #44):** General_Category Mn, Me, Cf and
  Default_Ignorable_Code_Point are 0.
- **Convention:** Ambiguous is 1, or 2 when the model asks for it; Hangul
  medial and final jamo are 0; controls are 0.
- **Cluster rule:** a cluster takes the width of its first character, except
  that a flag, an emoji ZWJ sequence and a cluster containing U+FE0F are 2.

## Tests

The laws are checked exhaustively rather than by sampling: for tab widths 1
to 4 and every text of up to four pieces drawn from a narrow letter, a wide
character, a tab and a line break, the tests check associativity, identity,
the homomorphism law, that equal actions give equal moves, and that `apply`
agrees with stepping the cursor directly. Changing either composition rule
for tab moves, or representing a width-1 tab as $U$, makes them fail.
